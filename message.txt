لو هتستخدم AI عشان يبنيه، **ما تديهوش Prompt واحد ضخم وتقول اعمل كل حاجة**؛ غالبًا هيطلع مشروع شكله حلو لكن مليان bugs. الأفضل تخليه يبنيه على مراحل.

لكن لو عايز **Master Prompt** يبدأ منه المشروع كامل، استخدم ده:

```text id="7c4nq"
أريد منك بناء مشروع CyberOps كامل باسم:

CyberIP Analyzer

فكرة المشروع:
أداة Mini SOC Investigation / Threat Intelligence تساعد محلل الأمن السيبراني على تحليل IP Address أو Domain أو URL أو مجموعة IOCs واستخراج المعلومات الأمنية والشبكية عنها، ثم إعطاء Risk Assessment مبني على الأدلة.

الهدف:
المشروع تعليمي ومخصص لـ CyberOps/SOC، ويجب أن يكون قابلًا للتشغيل محليًا وشرح كل جزء منه في مناقشة مشروع.

TECH STACK:
- Backend: Python + FastAPI
- Frontend: HTML + CSS + JavaScript في النسخة الأولى
- Database: SQLite
- API communication: httpx
- DNS: dnspython
- IP/network calculations: Python ipaddress
- Environment variables: .env
- Testing: pytest

لا تستخدم React أو PostgreSQL أو Redis في النسخة الأولى إلا إذا كان هناك سبب واضح.
ركز على أن يكون المشروع مفهومًا وقابلًا للصيانة.

CORE FEATURES:

1. IP ANALYZER

Class A/B/C مجرد معلومة Legacy.

3. THREAT INTELLIGENCE

Integrate with:
- VirusTotal API
- AbuseIPDB API

API keys يجب أن تكون في .env فقط.

لا تضع API keys داخل source code.

إذا لم توجد API key:
- لا ينهار البرنامج.
- يعرض "API key not configured".
- تستمر باقي التحليلات.

VirusTotal:
استرجع المعلومات المتاحة عن IP/domain/URL.
اعرض:
- malicious
- suspicious
- harmless
- undetected
- reputation
- detection ratio
- analysis date إن توفرت

مثال:
5 / 90 engines detected

لكن لا تقل:
"90 engines confirmed the IP is clean"

استخدم مصطلح:
"90 security engines reported results"

AbuseIPDB:
اعرض:
- abuse confidence score
- total reports
- country
- ISP
- domain إن وجد
- last reported date
- categories إن توفرت

مهم:
Abuse Confidence Score لا يعني احتمال أن الشخص Hacker.
هو مؤشر مبني على تقارير AbuseIPDB.

4. DNS ANALYZER

عند إدخال Domain:
استخرج:
- A
- AAAA
- MX
- NS
- TXT
- CNAME

وعند إدخال IP:
اعمل Reverse DNS / PTR lookup.

اعرض النتائج بطريقة واضحة.

5. DOMAIN / URL ANALYZER

المستخدم يستطيع إدخال:
example.com

اعمل:

- Domain extraction
- Scheme

- Port
- Path
- Query parameters

- IP addresses

- TLS certificate information إن أمكن بشكل آمن
- Redirect chain بشكل آمن

لا تقم بتحميل أو تنفيذ محتوى الموقع.

6. IOC EXTRACTOR

أضف صفحة يستطيع المستخدم فيها لصق Log مثل:

Failed login from 185.x.x.x
Connection to evil-domain.com
Hash: abc123...

استخرج تلقائيًا:
- IPv4
- IPv6
- Domains
- URLs
- MD5
- SHA1
- SHA256

اعرض قائمة IOCs.

بعد ذلك يستطيع المستخدم اختيار:
"Analyze All"

والبرنامج يحلل كل IOC.

7. RISK ASSESSMENT ENGINE

أنشئ Risk Engine مستقل.

لا تعتمد على مصدر واحد.

يجب أن يجمع الأدلة من:
- VirusTotal
- AbuseIPDB
- DNS
- ASN/ISP
- Reverse DNS
- Other available intelligence

ويحسب Risk Score من 0 إلى 100.

Categories:

0-20:
LOW

21-50:
MEDIUM

51-75:
HIGH

76-100:
CRITICAL

مثال scoring فقط، لا تعتبره حقيقة ثابتة:

VirusTotal malicious detections:
0 → 0 points
1-2 → +15
3-5 → +30
6+ → +40

AbuseIPDB:
0-20 → 0
21-50 → +10
51-75 → +20
76-100 → +30

Additional evidence:
Suspicious/malicious reports → additional points

يجب منع duplicate scoring لنفس الدليل.

ويجب أن يعرض البرنامج:
WHY the score was generated.

مثال:

Risk Score: 78/100
Verdict: HIGH

Evidence:
- VirusTotal: 5 malicious detections
- AbuseIPDB: 82 confidence score
- 143 abuse reports
- Suspicious historical activity

لا تقل:
"This IP is definitely malicious."

استخدم:
"High risk based on available intelligence."

12. SECURITY

طبّق:
- Input validation
- API keys في .env
- Timeout لكل external API request
- Error handling
- Rate-limit awareness
- لا تسجل API keys في logs
- لا تحفظ secrets في database
- لا تنفذ أي user input
- لا تعمل arbitrary command execution
- لا تعمل SSRF

بالنسبة لتحليل URLs:
لا تقوم بزيارة URLs بشكل مباشر من السيرفر بدون حماية.
ابدأ بتحليل parsing + reputation + DNS فقط.
أي HTTP fetching يجب أن يكون مع SSRF protection صارم أو اتركه خارج النسخة الأولى.

13. ERROR HANDLING

إذا AbuseIPDB unavailable:
استمر بباقي التحليل.

إذا DNS lookup فشل:
اعرض:
"No DNS information available"

إذا IP invalid:
اعرض validation error واضح.
```
